# Traffic Airflow Spark Pipeline

Курсовой проект: построение пайплайна обработки данных дорожного трафика с оркестрацией в Airflow, распределёнными вычислениями в Apache Spark и визуализацией в Grafana/Superset.

## Цель работы

Разработать прототип data pipeline для обработки данных дорожного трафика, поступающих от датчиков с секундной частотой.

Система должна обеспечивать:

- хранение исходных данных в ClickHouse;
- проверку наличия и качества данных;
- запуск пайплайна через Airflow;
- retry при ошибках отдельных задач;
- распределённую обработку данных в Spark на 3 worker-узлах;
- расчёт агрегированных показателей трафика;
- расчёт параметров локальной линейной регрессии по временным окнам;
- сохранение результатов обратно в ClickHouse;
- визуализацию результатов в Grafana/Superset.

## Предметная область

Исходные данные представляют собой секундные измерения дорожных датчиков.

Каждая запись содержит:

- `sensor_id` — идентификатор датчика;
- `measured_at` — время измерения;
- `value` — оценка интенсивности транспортного потока в машинах в час.

## Локальная линейная регрессия

Дорожный трафик обладает выраженной суточной сезонностью: интенсивность движения меняется в зависимости от времени суток, дня недели и характера транспортной нагрузки. Поэтому весь временной ряд нецелесообразно описывать одной глобальной линейной моделью.

В рамках проекта линейная регрессия используется локально — отдельно для каждого датчика и каждого временного окна. Такой подход позволяет оценивать краткосрочное изменение транспортной нагрузки на небольших интервалах времени.

На коротком временном окне динамику интенсивности движения можно приблизить линейной зависимостью:

```text
traffic = slope * time + intercept

где:

- `traffic` — значение интенсивности транспортного потока;
- `time` — время внутри рассматриваемого окна;
- `slope` — коэффициент наклона прямой;
- `intercept` — свободный член линейной модели.

Коэффициент `slope` используется как показатель краткосрочного тренда транспортной нагрузки:

- `slope > 0` — интенсивность движения растёт;
- `slope < 0` — интенсивность движения снижается;
- `slope ≈ 0` — транспортная нагрузка остаётся примерно стабильной.
